## 图片许可与项目原创 SVG

### 官方图片

三份研究稿逐项检查了所列网页和图注。**未取得照片、拓本、官方插画、视频或真实文物模型的离线打包与分发许可；本应用不使用这些网页图片。** “官方发布”“供图”或摄影署名、可以公开浏览、用于非商业比赛，都不自动授予复制、改编、远程嵌入或离线分发权。网页链接仅用于事实核对与来源入口；没有下载图片，也没有把图片转成纹理、拓本或模型。
