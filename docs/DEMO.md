## 2026-10-21 补充：当前模拟器环境与离线续写

用户本轮选择两台模拟器，没有腾讯云 HTTPS 域名。当前演示依赖开发机账号 / AI 服务和 HDC 反向端口；已有可选受信任公网 HTTPS 服务配置，尚无云部署，华为账号与原生可信组网未完成。鸿蒙分布式 KV 已接入本机不可变版本库，不代表已完成平台跨端传输。自建账号可在进程关闭后恢复原账号的离线档案，系统 ASSET 中的会话有效时重连免重新登录；12 小时到期后重新认证，离线记录继续保留。

A/B 表示演示角色，不是固定的实例名。本轮实际进程与监听端口对应为 A=`YunhejiSyncB` / `127.0.0.1:5555`，B=`Pura 90 Pro` / `127.0.0.1:5557`，与下文历史常用顺序相反。每次启动后核对 `hdc list targets`，需要操作或关闭某个实例时再核对 `Emulator.exe` 进程与其实际监听端口，不能沿用名称猜测。

离线续写作为答疑补充，按以下顺序展示：

1. A 登录演示账号并保存一页观察手账，确认正文已落盘。

## 三分钟主线（历史 2026-10-18 AI 观察手工路径）

本节保留 2026-10-18 当轮方鼎手工主线、预算与实测记录，适用其原包；当前 C08 操作与验收状态见顶部，不将下列历史结果累计为本轮通过。

目标：让评委看到“我问自己不懂的地方，应用带我看具体部位，依据可以核对，发现可以保存，并在同账号另一端重访”。

UI 改版注意：五城河洛的城市按钮在沙盘下方，点击后出现“查看档案”，不再需要点画布上的文字签；详情的视角工具在画布右下角小胶囊，不再占一整行；游客 AI 面板默认收起，登录后才直接展开。

1. 两台 API 26 设备 / 模拟器：A `Pura 90 Pro`（历史常用 `127.0.0.1:5555`），B `YunhejiSyncB`（历史常用 `5557`）。端口会变化，现场以 `hdc list targets` 为准。

4. 不展示账号、密码、密钥、token 或完整请求 JSON。AI 回答是“AI 参考解读”，不是馆方原文。

### 讲述稿（约 60 秒口播）

1. “这不是一个通用聊天框。问题只关于眼前这件方鼎，AI 只能使用应用里已经核对过的三条事实和三个原生观察部位。”

5. “换一台设备，登录同一个账号。这页手账已经在首页，AI 参考信息和画面一起回来。云端模型、原生页面和 HTTPS 同步是三件事，不把它说成鸿蒙端侧模型或分布式数据库。”

### 实测与边界（必须如实说明）

- 真实模型固定小样 **9/9** HTTP 200 且通过应用契约校验，单次 **1883—2409ms**；A 端界面实测约 2 秒返回。证据见[模型评估](test-results/2026-10-18-ai-observation-evaluation.md)。
- A/B 手工主线已完成：A 保存后服务端回读到 `aiAssist`、实际相机和原画幅；B 同账号经 HTTPS 收到，首页显示 AI 参考入口并实际回放。图集见[AI 观察图集](design/ai-observation/README.md)，原始结果见[测试报告第 25 节](TEST_REPORT.md#25-ai-观察导览与-ai-辅助手账2026-10-18)。
- **没有真人三分钟计时，也没有录像。** 单次模型耗时不能替代用户阅读、输入、滚动、设备切换和保存确认的总时长；现场排练后如实记录，不能仅靠修改预算宣布达标。录像仍按用户此前要求不由代理录制。
- AI 文本区不是 Canvas，不参与整幅像素比较；B 端只核对保存参数、页面文案和实际画面观感，没有做整屏像素差异断言。
- 未配置、超时、网络失败会显示真实原因并保留本地观察 / 手写能力；不要用固定台词或示例回答冒充在线 AI，也不要宣传成“零幻觉”。

## 三分钟主线（T11 已验收路径，历史 2026-10-17）

目标：让评委在三分钟内看懂一个文化细节，亲手保存带画面的记忆，并在同账号另一台设备上打开这条记忆、恢复观察位置。

完整主线：**首页主题 → 具体文化细节 → 有依据的对照 → 带画面手账 → 重返观察 → 同账号另一端。**

### 演示前准备

1. 两台 API 26 设备 / 模拟器：A `Pura 90 Pro`（HDC 实际 target，历史常用 `127.0.0.1:5555`），B `YunhejiSyncB`（历史常用 `5557`）。端口会变化，现场以 `hdc list targets` 和模拟器实例为准。
2. 两端安装同一 debug 主包；本机账号服务 HTTPS 18443 已启动，两端 HDC reverse port 已建立，`curl -k https://127.0.0.1:18443/health` 返回服务标识。
3. 两端提前启动、解锁，并用**同一演示账号**完成真实登录。账号应为空或只含明确标注的演示记录；计时从 A 端首页可见开始，登录与设备切换不计入三分钟。
4. 视频 / 投屏不展示账号、密码或 token。当轮登录会话只在进程内，退出进程后需重新登录；2026-10-21 已有账号档案与有效会话恢复，当前行为见顶部补充。

### 计时操作脚本

| 时间预算 | 实际操作 | 评委需要看见的结果 |
|---|---|---|
| 0—15 秒 | A 端首页点击“泥火成器”，进入庙底沟遗址 | 主题直达，核心问题明确；路线进度仍为真实值（空账号 0/4） |
| 15—40 秒 | 选择“西部陶窑”，向右转动观察 | 部位名、画面与事实正文同步；说出“西部陶窑与居住遗存都涉及西部”这一具体发现 |
| 40—70 秒 | 返回首页，从“文明连线”进入“双连壶与方鼎”，切到“口腹结构”，展开一处馆方依据 | 有具体差异与来源；说明不能由外形推断用途相同或技术演化 |
| 70—115 秒 | 回庙底沟，选“西部陶窑”，主动右转，点“留住此刻”输入短观察并保存 | 留下画面、摘录、个人文字与装饰；首页出现新记忆与 1/4，下一处为大河村 |
| 115—140 秒 | 点击 A 端首页最近记忆的画面 | 实际回到刚才的部位与角度，显示“已回到手账视角” |
| 140—180 秒 | 切到 B 端，展示首页同一条记忆的预览，点击画面回放 | 同账号收到同一条记录；B 端模型可见，恢复保存的实际观察位置 |

### 讲述稿（约 55 秒口播）

1. “云河纪把一次文化阅读，变成可以重访的个人记忆。”
2. “先从‘泥火成器’进入庙底沟。这里不是看一张文物照片，而是在方位沙盘上读一处有出处的细节：陶窑集中在西部，居住遗存也涉及西部。”
3. “再看一组有依据的对照。双连壶的两只壶体在腹部相通，方鼎是口腹近方的承托结构；我们只比较已核的器形、纹饰位置与出土记录，不从外形推断技术高低或演化方向。”
4. “现在把这一刻留住：选好部位和角度，写下一句自己的观察，印章和纸色都是这页手账的一部分。”
5. “保存后，首页把画面和文字一起记住；点开画面，就能回到刚才的视角。”
6. “换一台设备，登录同一个账号。同一条记录已经在首页，点开预览，模型和观察位置一起恢复。这是同账号个人信息的 HTTPS 同步，不是华为账号，也不是鸿蒙分布式数据库。”

### 实测与边界（必须如实说明）

- T11 设备路径：A 端真实保存 **1/1**（159100ms，含登录 / 注册与断言），B 端同账号接收、预览、回放 **1/1**（104368ms），Failure / Error / Ignore 均为 0；两端整幅 Canvas **1032×1050 零像素差异**，首页预览也逐像素相同。证据见[测试报告第23节](TEST_REPORT.md#23-双端新手账同账号闭环与主线排练2026-10-17)与[双端图集](design/memory-sync/README.md)。
- T13.1 主线排练设备用例 **1/1**，但自动化分段累计 **207.7 秒**（首页 2.6s、观察 30.0s、对照 39.6s、保存 98.1s、首页与回放 37.3s），包含 UiTest 逐步定位、稳定等待、截图和布局开销。**这不是真人三分钟计时，不能据此宣布“完整主线不超过180秒”。**
- 真人排练时优先压缩“保存”段：预写好一句短观察（如“在陶窑与居住遗存之间，记下我对庙底沟西部空间关系的观察。”），现场只改一两个词；印章 / 纸色各点一次即可，不在编辑器里长时间讲解。
- 对照入口位于首页“文明连线”中的“双连壶与方鼎”卡片；先用现有入口完整走一遍，若现场跳转明显拖慢，再考虑补一个最小快捷入口，不能在脚本里杜撰入口或用剪辑隐藏跳转。
- 录像：T13.2 本轮按用户指示不由代理录制，当前没有可播放的备用录像。现场如录制，应体现 A 端新保存与 B 端实际收到 / 回放的先后关系，跨设备切换和剪辑点如实说明；不用截图幻灯片或合成动画冒充。
- 内容仍为“初稿待校审”；模型为程序化学习示意，不是文物照片、测绘或考古复原。

## 拾遗手账与主题漫游（历史 90 秒路径）

入口：首页文化档案；路线入口为首页“黄河寻迹漫游”或 Dock 外右下角“我的”。以下为 2026-10-17 Step 3 的旧展示路径，保留作历史与备用演示；当前主线以上文三分钟脚本为准。

1. **凝视文化，约 15 秒。** 打开仰韶村遗址，转动器物示意视口，选取自己喜欢的角度。
2. **留住此刻，约 25 秒。** 点击“留住此刻 · 写一页手账”，选择“仰韶初光”和“青玉笺”，保留档案摘录。正文可写“从彩陶纹带里，记下今天的黄河线索。”，标签填“彩陶，黄河”，然后保存。
3. **翻开记忆，约 20 秒。** 返回“记忆”页并切换“画廊”，展示纸面、朱砂印、摘录与自己的文字。手账区位于统计之后、收藏之前。
4. **回到凝视，约 15 秒。** 点击卡片的“回到我的凝视”，回到同一档案和保存的视角，视口显示“已回到手账视角”。
5. **点亮路线，约 15 秒。** 回到“我的”，打开“寻夏记”并进入图谱；展示真实点亮的仰韶节点、路线进度和金色主题连线。仅保存这一处且无其他进度时为 1 / 5，已有记录时按实际值展示。

讲解重点：把一次文化阅读变成可以重访的个人记忆，再沿主题路线继续探索。“寻夏记”“泥火成器”“折叠的都城”均已接入；每个节点需达到 75% 显式探索进度或保存有效手账，整条完成才解锁纪念章。路线表达主题阅读顺序，程序化形态是学习示意，文化内容保持初稿状态。

实际页面见 [拾遗手账图集](design/memory/README.md)。该路径的设备结果对应各自旧包，不替代本轮双端手账结果。

本节保留当轮 20 条目录与交互画布的演示顺序；当前目录为 22 条，现有原生视口与验证边界见最新交接，历史包的条数和绘制方式按原记录保留。

## 双端记忆展示（2026-10-14—10-17 历史说明）

本节按当轮旧包保留；2026-10-21 的账号恢复、本机分布式 KV 版本库与 C08 设备验收状态见顶部。旧步骤中的会话限制和平台接入状态不作为当前实现结论。

先启动本机账号服务与两台模拟器，并安装当前 debug 主包。新实例的基础输入法设置需完成；使用基本模式即可。服务启动命令和 HDC 连接见 [账号说明](ACCOUNT_SYNC.md)。

1. 启动 A 端，先在独立登录页注册 / 登录演示账号。若已选择离线浏览，可从 Dock 外右下角“我的”进入登录；退出入口也在“我的”。登录后使用独立账号档案，原未登录记录继续保留。大学 / 学号可以留空，目前不参与手账或路线进度。
2. 进入任意文化详情，收藏并写一条短笔记，添加“旅途观察”等个人标签。
3. 在 B 端登录同一账号，打开“记忆”，查看刚保存的收藏与笔记；进入详情查看完整正文与标签。
4. 在 B 端修改一条观察，A 端返回同一详情，等待前台交换后展示变化。
5. 可选演示：暂时停止本任务账号服务，在已登录的 B 端修改笔记，说明已保存于本机。恢复同一服务后刷新，在 A 端查看新内容。
6. 删除笔记后在 B 端查看列表变化。后台保留删除墓碑，旧端重连不会将它恢复为活跃笔记。

当轮讲解时称为“同账号个人信息的网络同步”。它由本机独立账号服务支撑，该轮不是华为账号登录，也尚未接入鸿蒙分布式数据库。材质、导航和界面仍为原生 ArkUI / HDS；不以后台技术差异改变个人文化体验的产品定位。

现场截图 / 录像避免显示真实账号、密码或输入中的私人信息。可录收藏列表、合成示例笔记和另一端接收的过程；当轮版本在应用退出进程后需要重新登录，当前恢复能力见顶部补充。
