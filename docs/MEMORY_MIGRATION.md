# 拾遗手账数据兼容说明

记录日期：2026-10-17。目标工程：HarmonyOS 7 / API 26。此说明涵盖 Step 3 手账及三处重点观察画面的领域数据格式；界面、真实设备与双端结果由本轮测试报告另行记录，领域规则完成不代表双端或实际绘制已经通过。

拾遗手账沿用 `ArchiveRecord` 的 `kind: 'note'` 和 `schemaVersion: 1`，不改已有笔记 ID、正文、标签、更新时间、安装实例身份或 Preferences 名称。新增的四个字段均为可选值：

| 字段 | 格式与含义 |
|---|---|
| `stampType` | 印章装饰主题字符串；当前支持河洛拾遗、夏都寻踪、商都吉金、汴京梦华、仰韶初光 |
| `paperTheme` | 纸色字符串；当前支持 `rose`、`ochre`、`jade`、`ink` |
| `quotedPoemOrFact` | 用户保存时从档案已有摘要或概览摘录的文字；默认最多 160 字，不生成未经核实的诗词或新事实 |
| `snapshot3DPose` | 示意视角对象，原有字段为 `version`、`sceneType`、`yaw`、`pitch`、`zoom`、`hotspotId`、`sectionId`、`label`；本轮增加下表的四项可选信息；不是截图、实景图或考古复原文件 |

`MemoryPose.version` 继续为 `1`，`ArchiveSnapshot.schemaVersion` 继续为 `1`。为重建保存时的程序化示意，视角对象按需增加：

| 可选字段 | 格式与兼容边界 |
|---|---|
| `proceduralPreset` | 非空字符串，保存实际使用的程序化几何预设；不得以其他档案的默认预设替代 |
| `sceneRevision` | 正的安全整数，标记该预设的几何和热点修订；未知正修订号可以保存，播放时再核对 |
| `rendererProfile` | 非空字符串，标记绘制配置；当前可完整重建的是 `native-raster-v1`，未知配置仍保留原值 |
| `viewFrame` | 原虚拟画布 `{ width, height, textDensity?, dark? }`；宽、高和提供的文字密度须为正有限数，提供的 `dark` 须为布尔值；预览按原画布等比适配，不按卡片尺寸重新取景 |

本次采用按需扩展：旧快照可直接读取，缺少手账字段的普通笔记保持原样，读取和复制不会补上默认印章、纸色、摘录或视角，也不会更新其时间戳。旧笔记可以在记忆列表里展示；只有活跃笔记显式包含受支持的印章或纸色之一，才由 `isMemoryPostcard` 计作手账。用户主动保存为手账后，界面才写入所选元数据，并按既有逻辑时钟更新记录。

新客户端的 `parseSnapshot` 检查可选字符串与视角字段形状，保留合法值。未知印章、纸色、场景、预设与渲染配置字符串仍可归档保存；未知正视角版本或场景修订也不会被改成当前版本。界面是否能够显示或重放由对应支持名单决定，不能把未知场景误称为已恢复视角。角度与缩放必须为有限数值，缩放为正数；空热点和空主题表示未选择细分位置。存在但损坏的 `viewFrame` 或其他扩展会拒绝快照并沿用现有读取失败保护，不能悄悄删掉扩展后覆盖或清空原档案。

`copySnapshot` 复用 `copyMemoryPose`，逐字段复制四项新信息并深拷贝 `viewFrame`；编辑草稿和详情回放请求不能与已保存记录共享这个对象。缺省的字段继续缺省，包括旧视角中的四项新信息，不补写推测值，也不更改时间戳。确定性版本比较按固定字段顺序比较全部手账元数据及 `viewFrame` 内部字段，属性插入顺序不影响比较；原正文相同而预设、修订、渲染配置或原取景不同的跨设备记录也可返回落败冲突版本。时间戳、删除优先和设备 ID 的原有裁决顺序继续保留；删除仍是原笔记的墓碑，不删掉记录或其元数据，迟到的旧版本不能复活它。

纯函数 `resolveMemoryReplay(siteId, pose?)` 只读核对回放条件，返回 `state`、`canReplay`、说明文字以及可用的预设、修订、渲染配置与原取景副本：

| 状态 | 含义 |
|---|---|
| `ready` | 四项新信息齐全，且原取景同时记录了文字密度与明暗模式；对应档案、场景、预设、修订、热点 / 主题和相机参数均受支持，可以完整重建。界面仍须等实际绘制完成再显示恢复成功 |
| `legacy` | 合法视角可以打开，但缺少完整原取景信息；说明固定为“旧版视角，原取景未记录”。不生成声称等同当时画面的预览，也不补写旧档案 |
| `unavailable` | 缺少视角、档案不在当前目录，或版本、场景、预设、修订、渲染配置、选择值和相机参数不受支持；保留记录并给出具体说明，不代入首个档案，也不截断参数后宣称成功 |

当前只支持回放 `relic_inspector` 与 `stratum_slice`。原生相机与现有手势一致：`yaw` 为有限数，`pitch` 在 `[-0.5, 0.8]`，`zoom` 在 `[0.7, 1.6]`。归档层接受正有限画布尺寸，但实际绘制要求宽大于 24、高大于 46；不满足时回放给出无法绘制的说明。`viewFrame.textDensity`、`viewFrame.dark` 缺省的记录仍可归档，但不能计作完整重建。

缺少修订信息的旧视角按原 `sceneRevision: 1` 路径打开，原有全部预设仍可用；器物热点为 `form / pattern / story`，文化切片主题固定为 `overview / archaeology / history / poetry-travel`。本轮 `sceneRevision: 2` 提供下列三处，由 `MaterialObservation` 的定义核对；这次扩展只扩大可回放场景名单，没有新增字段、提高 schemaVersion 或批量改写旧记录。

| 档案 / 预设 | revision 2 热点 |
|---|---|
| 庙底沟 `smx-miaodigou / miaodigou_pottery` | `living / kilns / ditches` |
| 大河村 `zz-dahecun / dahecun_pottery` | `mouth / opening / paint` |
| 杜岭二号方鼎 `zz-duling-fangding / duling_fangding` | `centers / corners / frame` |

三处旧视角继续使用各自 revision 1 几何；旧大河村因而保留原单壶示意，不把新双连壶几何冒充当时画面。只要已提供的信息存在失配或不支持值，即使其他元信息缺失，也应为 `unavailable`，不能借 `legacy` 绕过支持检查。

升级前无需批量迁移，也不复制或重建安装实例 ID。既有 `previous_snapshot` 仍是落盘保护副本，不能当成新增的一键恢复功能。若需回退应用版本，应先保留包含新字段的完整快照，并让参与手账同步的设备使用本轮或更新客户端：未升级的旧客户端只复制旧字段，在编辑或保存快照时可能丢弃手账元数据，因此**不保证旧客户端保留新字段**。现有账号服务复用领域解析与合并，但旧运行进程仍需重启以加载更新后的规则；本说明不代表当前双端已复验。

时令标签采用记录时间在本机日历中的常见月日分段，始终显示“时令近似”，不作为精确节气历法。印章名称是可切换的手账装饰主题，不替代档案的断代、王朝归属或器物出土结论；摘录继承对应档案“初稿待校审”的内容状态。
