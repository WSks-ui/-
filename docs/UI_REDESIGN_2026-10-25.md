# 界面重构记录 · 2026-10-25

## 1. 为什么改

用户判定：「像网页而不是手机 APP，看不懂」。在模拟器（1256×2760）逐屏核查后，问题集中在四处，且都不是配色问题：

| 屏 | 具体表现 | 性质 |
|---|---|---|
| 漫游首页 | 250dp 高的装饰河景横幅，下面是一排等权重纯文字「01 三门峡 02 洛阳…」 | 横幅 + 无选中态的文字链，不是入口 |
| 文化库 | 标题 + 分段 + 搜索 + 城市 + 年代 + 类型 + 范围 + 排序 + 计数，共 9 层控件，首屏看不到一条内容 | 把筛选面板当页面 |
| 文化库/收藏 | 双列海报卡，标题居中、摘要居中、按钮居中 | 网页长图册版式 |
| 底部栏 | 三个页签 + 一个独立悬浮圆球「我的」，与胶囊边缘相叠 | 入口关系不清 |

共同点：**信息块居中、层层堆叠、装饰占据首屏**。这三件事叠加起来就是"网页感"。

## 2. 改了什么

### 2.1 应用栏

- 品牌胶囊「云河纪」+ 单枚书签 → **当前页标题 + 搜索 + 收藏**。
- 标题跟随页签：漫游 / 文化库 / 记忆。用户始终知道自己在哪一页。
- 保留 `top-collection`、新增 `top-search`；`top-brand` 移除（无测试依赖）。

### 2.2 漫游首页（第二轮：河卷回归）

第一轮把河卷横幅整块去掉，改成城市胶囊 + 卡片。用户否决：首页失去了主视觉。
第二轮按「参考之前的首页」调整为：

- **恢复河卷**（`riverRoll`）作为首屏主视觉，题签仍是原生节点，点题签即可换城。
- 河卷只显示当前城（1120 逻辑宽 ≈ 手机 2.8 屏），因此在河卷下方补一条
  **卷目条**：五城等分、选中项朱砂下划线、已建成的城带金点，
  与题签同语义。`roam-pick-<id>` 挂在卷目条上，题签保留 `roam-city-<id>`。
- 去掉页内 30 号大标题（顶栏已有「漫游」），换成一行 11 号上下文，
  省出的高度让河卷 + 卷目 + 「回城」主按钮同屏出现，不必先滚一下才看到主操作。
- 河面底部补画布内渐隐（28dp，渐到纸色），消除水色被卡片硬切的一条边。
- 开卷卡：标题 21/24 加粗、卡片圆角 12、主按钮 48 高圆角 10。
- 两个入口行：方框描边字 → 32dp 圆形色块 + 15 号标题 + 15 号箭头。

### 2.3 文化库

- 9 层控件压到 5 层：结果数/排序/重置一行 → 分段 → 搜索 → 三维下拉一行 → 范围芯片一行。
- 三个下拉各 100dp 并排，正好放进 327dp 可用宽度，不再横向裁切。
- 「排序」从芯片行移到结果行，用 11 号文字切换，避免右侧被切一半。
- AI 观察入口从列表之前移到列表之后：它是延伸能力，不该占首屏。
- **目录与收藏从双列海报卡改为单列列表**（复用已有 `SiteRow`）：
  64dp 缩略图 + 16 号标题 + 12 号元信息 + 单行摘要 + 收藏书签 + 已读点 + chevron。
  行 id `site-row-<id>`、容器 id `archive-library-grid` / `archive-site-grid` 全部保留。

### 2.4 文化篇章列表

- 居中的标题 + 底部独立按钮 → 单行列表：标题 15、类型/年代 11、目标 12 两行截断。
- 收藏从文字块改成 36dp 书签图标按钮（实心/描边两态）。
- 展开后才出现正文、来源与「走进这一段」（36dp，圆角 8）。

### 2.5 记忆

- 页内标题 30→20；写一页 40→34 高；管理 38→32；分段 40→32、内圆角 6。
- 空态卡片：图标 64→52、上下留白 28→20、标题 15、说明 12。
- 空态主按钮：浅色整条 + 居中文字 → **实心主色 46 高圆角 10**。

### 2.6 详情页

- 「留住此刻 · 写一页手账」：浅色横幅 → 实心主色 46 高圆角 10。
- 正文行高 28→24、字号固定 15，减少"网页段落"的松垮感。

### 2.7 底部栏

- `barBottomMargin` 从 -14 收到 8：标签不再被压到屏幕外。
- `barOverlap` 实测不能关：关闭后「我的」miniBar 直接消失。
  因此保留穿透，把 `dockClearance` 提到 104，静止时内容不被遮住。
- 「我的」圆内图标 23vp→20vp、文字 12→10，并保留 `profile-entry` 与
  `profile-entry-label`（多个设备用例依赖）。

## 3. 后续改版必须遵守的四条

1. **首屏先给内容，再给控件**：筛选不超过两行，其余收进抽屉或横滑行。
2. **列表项左对齐**：缩略图 + 标题 + 元信息 + 右箭头；卡片内不居中排版。
3. **一个页面只有一个主按钮**，实心主色、≥44dp 高；次要动作使用文字或图标。
4. **不新造悬浮控件**：底部栏、标题栏的位置与高度改动前，先跑设备用例，
   `profile-entry`、`top-collection`、`site-row-*`、`archive-*-grid`、`roam-pick-*`
   这些 id 一旦缺失，测试会直接失败。

## 5. 已知未处理

- 河卷横向宽度为 1120 逻辑像素，一屏只容纳约一城；若要一屏看到更多城，
  需要重画河道比例，而不是继续压缩题签。
- 详情页正文仍在固定行数处截断（`…`），需要改成可展开或分节。
- 「我的」miniBar 与胶囊仍是两个视觉块；若要合成一个四页签底栏，
  需先把 `ProfilePage` 嵌成 TabContent，并同步改 `profile-entry` 的用例。
- 漫游关卡页（三幕）与个人页未在本轮重排，只继承了主色与圆角。
