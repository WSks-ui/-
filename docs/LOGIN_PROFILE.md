# 独立登录与“我的”页面

日期：2026-10-16。按用户要求，将“档案”中的个人账号 / 偏好拆到独立“我的”，并在启动时先显示登录页面。

## 入口与职责

应用启动先显示原生 `LoginPage`，主内容与 Dock 尚未创建。用户可登录 / 注册，认证成功后进入河迹首页；也可明确点击页底“离线浏览本机档案”，访问原有未登录记录。认证失败停留在登录页，退出登录重新回到该页。本机档案损坏时保留读取失败提示与重试入口，不初始化覆盖。

底部仍只有河迹、记忆、档案三个 `TabContent`。右下角“我的”使用 HDS 官方 `HdsTabsFloatingStyle.miniBar`，与三项 TabBar 并排，在 Dock 胶囊外独立显示。点击进入 `NavDestination`，返回后仍处于之前选中的主页面。

| 页面 | 内容 |
|---|---|
| 登录 | 账号 / 密码、注册切换、学习档案选填区、错误反馈、明确的离线浏览入口 |
| 档案 | 本地保存状态、文化资源数量、浏览数量、数据格式与离线文化资源说明 |
| 我的 | 账号身份、真实同步状态、教育计划占位、阅读偏好与关于信息 |

“我的”没有新增第四个页签，不以自绘玻璃或绝对定位覆盖按钮代替原生材质。独立 miniBar 沿用 HDS 的系统材质、关闭光感与减少动态策略。固定导航区的图标采用 vp，标签最高使用 1.2 倍字体；其余正文继续按系统字号缩放，避免 1.5 倍字体挤进固定高度圆形栏。

## 大学与学号占位

登录 / 注册页的“学习档案”可展开填写大学 / 院校名称和学号，均为选填。教育计划仍为准备中，不进行学籍认证、计划生成、课程安排或进度计算。

填写的信息仅在本次登录后的“我的”页面展示，学号只显示“已填写”，不展示具体号码。字段不会加入账号认证请求、服务端数据库、Preferences 或个人档案同步；退出 / 重新进入登录页或重启后清除，不影响同账号收藏 / 笔记。后续若决定持久化教育信息，需单独定义用途、用户编辑方式和账号数据范围。

## 实现与数据约定

- `LoginPage.ets` 负责启动表单、键盘收起和错误反馈；不直接访问网络或存储。
- `ProfilePage.ets` 负责个人页，`AccountPanel.ets` 只展示账号状态 / 操作，不再包含登录表单。
- `Index.ets` 负责是否进入主内容、账号切库与路由清理；初始本机读取完成前阻止认证，避免迟到响应覆盖账号快照。
- `HarmonyEffects.ets` 集中配置原生 miniBar。参考日期 2026-10-16，本机 HDS 类型声明中的 miniBar 为 HarmonyOS 6.1 / API 23，水平布局为 API 24；当前工程仍为 API 26。
- 未改变 schema v1、正式游客库名、账号库规则、记录字段、删除墓碑或 Repository 流程，无格式迁移。正式用户数据不清空。
- 现有会话仍只在进程内；重启后需重新登录。网络服务、正式部署和华为账号 / 分布式数据库的边界见 [账号说明](ACCOUNT_SYNC.md)。

验证使用真实页面操作与独立测试 Preferences，不通过 debug 参数跳过登录界面。旧离线路径测试同样先点击“离线浏览”；账号测试通过独立登录页并从“我的”退出。截图只含空表单与本机模式，真实注册 / 登录场景不公开账号、密码或学号。

最终页面 / 账号专项为 **4/4**，包含注册、错误密码拒绝、退出后回到登录页、再次登录恢复收藏及清除教育占位。原始结果与范围见 [测试报告第 13 节](TEST_REPORT.md)，12 张真实原图见 [页面图集](design/profile/README.md)。
