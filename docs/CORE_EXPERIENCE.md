# 核心体验成型阶段

阶段名称：**核心体验成型阶段**。执行基线：HarmonyOS 7 / API 26，页面使用 ArkUI 原生实现，现有同账号数据通道继续使用 HTTPS。

这一阶段把作品收敛到一条可体验的主线：**首页主题 → 具体细节 → 有依据对照 → 带画面的手账 → 视角回放 → 同账号另一端**。研究文档、事实数据和原创 SVG 是资料基础，不等同于比较页或图文手账 UI 已完成。

## 体验顺序与实现边界

1. 用户从首页主题进入一个重点对象，先看到明确问题和具体细节。
2. 对照内容按事实来源逐项并列，让用户能检查两件对象的器形、纹饰位置和出土记录。
3. 用户把观察到的画面、个人文字和当时视角一起留在手账。
4. 用户从手账重返对应档案和场景，恢复角度与热点；不能恢复时给出明确提示。
5. 同一账号在另一端接收该条记录并打开相同的可重建视角。

保持现有 HarmonyOS 7 / API 26、ArkUI 原生页面与 HTTPS 账号同步通道。复用现有文化视口，不重写引擎，不把同步改为多人协作或分布式 KV，也不扩展为生产化治理项目。本阶段不新增城市路线徽章，不改变现有主题路线点亮规则。

## 对照数据与可解释范围

T03 的一组对象对照固定为大河村双连壶与杜岭二号方鼎，三维度如下：

| 维度 | 已核内容 | 能看出什么 | 不能推断什么 |
|---|---|---|---|
| 器形 | 双连壶由两个并列壶体组成，腹部以椭圆形通口相连；方鼎口、腹截面基本为正方形，有双立耳和四足。 | 比较两个对象如何组织器口、腹部连接和支撑结构。 | 不能由外形断定用途相同、容量、使用方式，或双连壶演化为方鼎。 |
| 纹饰位置 | 双连壶腹部为红衣黑彩平行横线及竖、斜短线；方鼎上腹四壁正中和四个折角各有一组兽面纹，乳钉纹带另沿两侧及近底端分布。 | 比较绘彩与凸起纹饰的表现和位置安排。 | 不能据此判断技术优劣、纹样寓意、宗教对象、传播方向或工艺演化。 |
| 出土记录 | 双连壶 1972 年出土于郑州大河村遗址，馆方定为新石器时代仰韶文化文物；方鼎 1974 年 9 月出土于郑州张寨南街青铜器窖藏坑，馆方定为商代前期青铜礼器。二者均现藏河南博物院。 | 对照两件具体对象已核的发现地点、年份、馆方年代和现藏信息。 | 发现年份不是器物制作年份；不能据此建立同层位、同人群、连续传承或因果关系。 |

这些内容来自各自的对象来源，不从共同城市或共同博物馆自动生成结论。三维度事实数据已放入 `entry/src/main/ets/data/MaterialStudyCatalog.ts`；T06 的完整对照页仍未完成。

## 下一里程碑已确认的代码落点

以下为只读核对结果，尚未实施，不计作T04—T13完成：

- **先做对象场景。** 当前 `CulturalNativeScene` 中庙底沟与大河村仍会落到单陶壶，杜岭为实心盒体，热点固定为 `form / pattern / story`。大河村样板应先表达两个壶体、壶口与腹部通口；仅更改按钮文字不能完成精细观察。当前三张分析SVG可以作为内容依据，不能冒充原有3D已经表现这些结构。
- **预览复用同一绘制。** `CulturalNativeRenderer.draw → nativeCulturalScene → objectRasterFrame` 是参数重建的现有入口。Raster有固定边距和偏移，不能直接换成卡片尺寸后声称构图一致；应保留保存时虚拟画布，等比放入卡片。拟按需增加可选的预设、场景修订、渲染配置与原取景信息，修改时必须同时覆盖MemoryPose校验、深拷贝、冲突比较和详情请求复制，并补旧记录说明。
- **恢复先验证再报成功。** `SiteDetail` 当前吞掉初始视角解析错误，不支持场景会直接返回；`CulturalEngineViewport.applyMemoryPose` 对不匹配参数直接返回，静默限制缩放后仍可能显示“已回到”。`Index` 还存在未知siteId代入首条档案的路径。T08应明确区分不支持、旧版信息不完整和完整恢复，实际绘制后才发布成功状态。
- **双端只跑本条主线。** 本次只读检查时仅有一台模拟器在线，旧A/B端口分配已经不能直接沿用；另一实例已存在但未启动。进入T11时先通过Emulator与HDC列表确认新增target，再复用账号fixture、独立库和精确方法过滤，分为A发布、B接收/预览/回放两阶段；不要整套运行旧账号外观、离线与墓碑场景。现有HTTPS交换保留四项手账元数据，新增视角字段后服务需重新加载领域解析器。
- **备用录像需要真实录制。** 当前设备无`screenrecord`/`screenrecorder`命令，HDC命令记录不是屏幕录像。本机API26 SDK提供`media.createAVScreenCaptureRecorder`；T13需实际录制、导出并检查成片，当前不登记录像完成。
