## 图谱实现

页面、导航、账号、档案索引、关联解释、对照和个人专题继续使用 ArkUI。仅关系画布使用包内 ArkWeb：`graph.html`、样式、布局脚本和 Three.js 全部随应用离线携带，没有 CDN、远程字体或图谱网络请求。

- Three.js r180 使用 WebGL2 绘制节点、曲线和选中连线上的装饰粒子；不可用时使用 Canvas 2D，布局与节点选择共用同一份状态。
- 力导向采用斥力、弱弹簧、阻尼、标签碰撞与边界约束。初始位置确定，更新选择时保留已有位置，拖动后保持节点在画布内。
- 背景只展示各节点最相关的两条边，选中节点显示全部真实关联；下方列表保留完整理由。规则仍来自 `CultureConnections.ts`，不改变已有业务逻辑。
- 图形点选通过限于当前节点 ID 的 `javaScriptProxy` 回传 ArkUI。下方保留原生双列档案索引，可展开全部 15 处，并继续打开档案或双档案对照。
- 旧 `CultureGraph.ets` 保留源码。它的五节点布局不能直接用于 15 条内容；运行时降级使用同布局的 Canvas 2D，Web 整体不可用时保留原生索引。
- 深浅配色读取当前语义颜色资源，独立于材质开关 `lightEnabled`。画布标签适配已验证的 1.5 倍字体；原生索引与正文保持系统字体缩放。
- 开启减少动态时直接计算稳定布局，停用持续动画。画布不可见、页面隐藏、对照打开或 Web 文档进入后台时停止动画帧，文档退出时释放绘图资源。

粒子流动、节点晕圈属于图谱装饰，不代表历史流向、同步状态或鸿蒙原生沉浸光感。原生标题栏、三项 Dock 和独立“我的”仍由已有 HDS 适配提供。

任务书的示例实际上是 Canvas 2D，并未引用 Three.js；本实现另行打包实际 Three.js。任务书将 `lightEnabled` 当作深色模式的示例没有沿用。首页的 `cityIndex()` 实际已使用横向 `Row`，并非任务书 3a 描述的竖列，本轮没有重做这部分。现有进度记录的 `kind` 实际为 `progress`，不能按任务书中尚未实施的 `visited` 示例直接写入数据。

## 依赖与桥边界

Three.js 固定为 0.180.0，MIT 许可随包携带，版本、上游地址、原包完整性与产物 SHA-256 见 [NOTICE](../entry/src/main/resources/rawfile/three/NOTICE.md)。离线产物只包含实际使用的绘制接口，不要求用户安装 Node 或运行构建器。

Web 页面只加载本包 rawfile；禁用网络图片、DOM 存储、数据库、定位、混合内容与一般文件访问。CSP 禁止网络连接、子框架和表单提交；代理只有节点选择和就绪通知两个方法，没有账号、存储或网络能力。原生页面只传递文化目录与关联信息，不传账号、令牌、笔记正文或教育资料。

SDK 类型核验及实际设备范围见 [技术核验](HARMONY_RESEARCH.md)。本轮测试与真实截图以 [测试报告](TEST_REPORT.md) 的新增记录为准，不能由构建成功推断设备功能或动态性能通过。
