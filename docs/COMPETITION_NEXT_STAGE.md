## 三、任务详情

### C01：固定最终设备、包与服务

责任边界：`build-profile.json5`、`domain/AccountSync.ts` 的端点规则、`sync/AccountSyncClient.ets`、`sync/WaterSituationClient.ets`、服务配置与演示脚本。签名材料只在用户本机配置，不能写进公开任务书或仓库。

审查时限制为非 DEBUG 禁用服务、公网域名被拒绝；本轮已增加独立公网配置入口并统一三类客户端加载，未提供公网域名时 debug 继续走本机配置。用户选择模拟器演示，先以该实际路径验收；代码支持公网配置不等于已经部署。

交付：确定手机/平板或两台演示设备；固定局域网/公网网络路径与受信任证书；配置明确的演示包/发行包行为；记录主包哈希；两端实际安装启动，AI、账号和必要接口可达。保留用户原签名配置。

验收：离开开发机回环端口转发后，按实际比赛网络路径启动并使用；若比赛选择带开发机局域网，则完整记录该路径及依赖，不写成已经独立上云。

### C02：真实鸿蒙分布式通道

责任边界：新增平台适配放 `sync/` 或 `data/`；保持 `ArchiveDomain` 的纯函数边界。迁移说明写入 `docs/`，测试只用独立库。

实现内容：核对当前 SDK、设备系统能力、可信关系、权限与签名；接通实际支持的分布式数据库服务；完成变化监听与确认；沿用记录级版本、时间戳、稳定并列裁决、墓碑和 AI 视角元数据。

不能用全量 JSON 单键覆盖代替记录级合并。底层数据库的冲突机制与领域 LWW 必须有明确关系，落败版本需要可读取或保留；不能假定改成 KV 就自然满足离线并发。

迁移要求：读取旧 Preferences→校验→写新库→回读核对→成功后切换；失败保留旧库。核对稳定 ID、活跃记录数、墓碑、正文、标签、学习进度、印章纸色、场景修订、相机与 AI 冻结事实。不得用新空库覆盖旧档案。

设备验收只做赛题主线：A 新增收藏与手账→B 收到；B 修改→A 收到；两端离线改同一条→重连后较新版本一致；删除墓碑不复活；学习进度随个人数据到另一端。保留原始事件与落盘证据，不只截图“同步成功”。

### C03：同账号身份与离线冷启动

责任边界：认证适配、账号工作区、本机恢复入口、登录/退出编排。设备 ID 是安装实例，不能作为华为账号身份。

交付：按真实可用的华为账号授权完成稳定身份映射；账号工作区可在离线冷启动恢复；网络会话失效与本地可读分开；退出、切换账号、游客数据边界明确。没有真实账号授权时如实标注当前替代方案。

验收：在线登录并保存一页→关闭进程→服务不可达→冷启动→仍能打开并编辑这页→恢复连接→同账号 B 收到。再切换另一账号确认不会看到前一账号档案。该检查围绕实际演示数据，不开展无关生产安全扩项。

### C04：补齐内容维度与资料层级

责任边界：`HeritageCatalog.ts`、必要内容元数据与检索规则、`IMAGE_CREDITS.md`、条目级研究说明。

交付：五城范围内有依据的龙山相关条目及窑址条目；如采用多期遗存标签，解释与主年代的关系并提供来源；保留旧 ID 与既有收藏/笔记对应。每条具备概览、发现、历史、访问索引与出处；诗文可关联城市/河流，但写明关联对象。

验收：在真实档案页用“城市 + 年代 + 类型”组合命中对应条目；龙山、窑址不再全空；断开服务仍可看图文；新增资源无缺文件；不填未经核实的票价、考古结论与诗词。图片许可、作者和原文件页可追查。

### C05：让真实同步看得见

责任边界：`AccountView` 或对应新状态模型、平台适配状态、账号面板、手账同步提示。

交付：展示设备来源与去向；本机待传、正在交换、对端确认等真实阶段；最后成功时间来自实际完成事件；冲突数区分累计历史与待决项目。只有可计算的总量才画进度百分比。

验收：A 保存时状态随真实事件变化；服务不可达时保留本地内容，成功时间不跳；B 收到并落盘后能核对同一记录；冲突历史可打开，明确胜出版本、时间和处理规则。未接入通道显示未接入。

### C06：可带走、可恢复的个人记忆

责任边界：平台文件选择与写入、备份格式与预览、数据与存储页、恢复规则。纯数据校验可放领域层，文件 API 放平台层。

交付：导出实际文件；导入后先显示备份日期、记录数与内容类型；用户确认后按合并规则恢复；保留目标设备身份与原账号边界。备份包含收藏、标签、进度、手账视角、装饰与 AI 依据，不包含认证密码或访问令牌。

验收：用独立测试档案导出→另一独立档案恢复→逐项对照；损坏备份显示原因并不改当前库；墓碑不会使旧笔记复活。此前“复制 JSON”继续可作为辅助工具，不能替代完整验收。

### C07：内容优先的记忆与页面分工

验收：正常字号原生画面中，记忆第一屏可同时看到首条标题、正文摘要与主要操作；条件切换、清除、无结果、返回后状态一致；收藏/手账分区清晰；点击用户已有纸页入口仍能到正确页面。
