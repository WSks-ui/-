## 视口元数据与学习主题

`domain/CulturalContent.ts` 以档案 ID 单独维护 `proceduralPreset`、五城西向东展示顺序和学习主题，不扩展 `ArchiveDomain.ts` 的 schema 或必填字段。20 个档案均有显式预设映射，预设标识只选择程序化几何示意，不是实测模型、遗址复原或器物鉴定结论。未提供预设时显示通用器形示意，不代表某件仰韶器物。

四个稳定学习主题为 `overview`、`archaeology`、`history`、`poetry-travel`；最后一项合并现有 `poetry` 与 `travel` 文本。每项占 25%，代表用户明确标记完成一个主题后的阅读进度。它们是内容导航，不表示遗址具有四层真实地层。应由用户点选“标记已探索”，且只在本机提交成功后更新页面状态。

## 记录兼容

进度继续使用已有 `kind: 'progress'` 记录与 schema v1 信封，不改变收藏、笔记、`tags` 或墓碑规则。每个学习主题写一条独立记录，逻辑 ID 为 `progress:<siteId>:<sectionId>`，正文是版本 1 的主题完成标记；不同设备完成不同主题时可以分别合并。删除仍依赖已有 `deleted` 墓碑语义。

旧详情打开记录 `id: progress:<siteId>`、`body: 'opened'` 只解码为“曾打开过”，进度为 0%；不能迁移成 25% 或 100%。无效正文、未知版本、其他档案记录与已删除记录不增加进度。该设计只追加新进度记录，不需要改写旧记录或迁移笔记格式。
