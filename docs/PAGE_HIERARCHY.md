# 页面功能、层级与 AI 入口检查

更新日期：2026-10-18。目标：HarmonyOS 7 / API 26 原生工程。本文承接用户对“记忆、档案、我的”页面功能和层级的反馈，记录本轮已经完成的调整和下一阶段建议。实际画面见[页面图集](design/page-hierarchy/README.md)，设备结果及保留失败见[测试报告第 27 节](TEST_REPORT.md#27-页面功能层级与-ai-重访2026-10-18)。

## 1. 页面职责与层级

| 入口 | 用户要做的事 | 一级内容 | 二级页面或操作 |
|---|---|---|---|
| 河迹 | 发现文化线索，开始一次探索 | 当前主题、最近记忆、AI 方鼎入口、五城河洛、纸页入口、城市索引与检索 | 文化档案详情、文明图谱、最近手账详情或原视角 |
| 记忆 | 找到自己留下的内容，再读或再看 | 手账 / 收藏分区；手账搜索、AI 筛选、列表 / 画廊；收藏分类 | 手账全文 → 编辑、重温、原档案、删除；方鼎手账可带入 AI |
| 档案 | 有目的地查找遗址、文物和文化线索 | 20 处离线目录；关键词、城市、年代、类型、可 AI 观察筛选与重置 | 文化档案详情；方鼎观察导览 |
| 我的 | 看个人概况，管理账号与使用偏好 | 账号概览、手账数与 AI 手账数、简短菜单 | 我的主题漫游、账号与同步、阅读偏好、关于与资料说明 |
| 文化档案详情 | 观察文化对象，核对资料，留下记忆 | 模型与部位、观察说明、参考资料、收藏与手账 | 资料原地展开；AI 面板；手账编辑 Sheet；推荐档案 |
| 手账详情 | 阅读一篇完整的个人记忆 | 正文、标签、原视角、摘录、原问题、保存时的 AI 依据 | 编辑、重温、带这页问 AI、原档案、确认删除 |
| 登录 / 注册 | 登录同一人的账号以使用在线 AI 和同步 | 账号、密码、登录 / 注册、离线浏览 | 成功后进入河迹；离线浏览进入本机档案 |

“我的”沿用 Dock 右侧独立入口。主题漫游、同步设置和资料说明均通过 Navigation 进入二级页，系统返回回到上一层；手账编辑仍复用文化档案中的原生编辑器。

## 2. 本轮发现的问题与实际修正

| 发现的问题 | 对用户的影响 | 本轮处理 |
|---|---|---|
| 记忆同时堆放笔记和收藏，卡片以摘要为主 | 难以分清内容类型，也缺少稳定的全文阅读位置 | 手账 / 收藏分区；新增按记录 ID 导航的手账详情；正文、标签和曾经的问题可搜索 |
| 记忆卡片打开操作语义不清 | 阅读全文和恢复模型视角容易混淆 | 使用“读手账”和“重温”两个明确动作；方鼎额外提供“问 AI” |
| 编辑后返回详情仍显示旧正文 | 实际已保存，但用户可能误以为修改丢失 | 返回及快照变化时按 ID 读取当前记录；用记录更新时间重建 ArkUI Builder 内容区；设备用例核对磁盘和显示正文一致 |
| 档案页缺少完整检索层次 | 从浏览目录走向具体对象的路径不够明确 | 增加关键词、城市 / 年代 / 类型组合筛选、结果数、空状态、重置及“可 AI 观察”筛选 |
| 我的页直接展开三条路线与大量说明 | 账号、主题和设置在同一长页面里竞争注意力 | 改为概览与菜单，具体功能进入二级页；关于页去掉重复标题 |
| AI 主要藏在详情，保存后难以再次使用 | AI 与个人记忆的关系不明确 | 档案提供明确观察入口；记忆支持 AI 筛选、保存时依据及带着单篇手账再问；我的显示真实 AI 手账数并可跳转 |
| AI 聚焦动作之后，模型可能不在当前视野 | 用户看到回答，但难以感知动作结果 | 聚焦后回到原模型，显示已聚焦反馈；“继续追问”回到原面板并保留问题与回答 |
| 延迟请求输入焦点可能抛出异常 | 快速返回或页面暂不可聚焦时会退出应用 | 对便捷焦点请求捕获系统异常，保留手动点选输入；退出后的回调检查页面状态 |
| 带回手账的观察文字可见行数过少 | 较长观察在提问前不便检查 | 增加个人观察输入框高度；长于 300 字时明确提示截取范围，原手账保持完整 |

本轮没有改笔记数据格式。全文编辑沿用原记录 ID，保留原视角及已有 `aiAssist`；删除仍写墓碑。旧普通笔记继续按普通笔记展示，不自动补造 AI 参考信息。

## 3. AI 现在如何融入各页

| 页面 | 已实现的 AI 行为 | 范围 |
|---|---|---|
| 河迹 | 直接开始方鼎问题；最近真实手账显示 AI 辅助标记 | 延用现有首页路径 |
| 档案 | “和 AI 一起看方鼎”卡片直接进入对象；“可 AI 观察”筛选只返回真实支持对象 | 当前为 1 处方鼎 |
| 文化档案详情 | 自由提问、上下文追问、聚焦具体部位、查看对应依据、整理个人观察为可编辑草稿 | 登录且服务可用时请求真实模型 |
| 记忆 | AI 辅助手账筛选；手账卡和详情可“带着这页问 AI”；查看保存时冻结的事实依据 | 方鼎普通手账也能带入个人观察；无 `aiAssist` 的记录不计作 AI 辅助手账 |
| 我的 | 显示真实 AI 手账数量，点击进入记忆的 AI 筛选；提供观察导览入口 | 统计从当前账号活跃笔记派生 |

重访只预填这一篇手账的问题和正文，用户点击“提问”后才发送。服务端明确将带入文字标记为个人观察，不作为已核史实；不会把整个个人记忆库放进本次请求。保存时依据与新一次模型回答分开，重访进入时没有伪造的旧回答。

目前增强了入口、记录和重访之间的联系；模型知识范围仍限于方鼎。其余 19 处的离线阅读、手动观察、收藏和手写手账正常提供，不能宣称整个目录已经支持 AI。

## 4. 检查范围与仍需改善的地方

- 本轮设备验证集中在三个有实际改动的路径：档案筛选与个人页层级、手账全文编辑 / 回放 / 删除、真实 AI 观察 / 保存 / 重访。历史首页、登录、图谱、对照和双端结果保留在各自测试报告中，没有重跑为本轮全量覆盖。
- 首页与档案仍有部分检索能力重叠。后续适合让首页承担精选发现，完整检索集中在档案；这一项应先由用户体验评审确定，避免再次削减用户已选择保留的首页内容。
- 主题漫游已从我的概览移出，但其二级页仍长。下一轮可将三条路线先收为摘要卡，点选路线后看节点、进度与纪念章。
- 文化档案详情的观察、资料和个人笔记仍形成较长页面。可继续压缩首屏信息并明确“观察 / 阅读资料 / 我的手账”的定位入口，保持模型、回答和资料之间的连续操作。
- 记忆页搜索目前是本地文本匹配，不是 AI 语义检索；我的统计也是本地派生，不应标成 AI 总结。
- 文化目录仍为初稿待校审；学习模型仍是程序化几何示意。同账号同步是现有 HTTPS 服务，不能称为已接入鸿蒙分布式 KV。
