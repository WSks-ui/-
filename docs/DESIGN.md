## 参考依据

实际阅读了参考工程的 `components/Theme.ets`、`components/HomeBackdrop.ets`、`pages/HomePage.ets` 和配色资源，并查看 `docs/images/home.jpg`、`wardrobe.jpg`、`profile.jpg`。参考工程保持只读。

采用其暖白和玫瑰色调、粉彩辅助色、错落的首页纸片、倾斜的小贴纸、双列图文目录与分组信息卡。衣物照片、业务文案和同步实现不属于本项目参考范围。

| 规则 | 云河纪实现 |
|---|---|
| 暖白页面，三级文字 | `canvas #FDF8F6`；主文字 `#2B2225`；次要文字 `#7A6C70`；提示文字 `#A7989C` |
| 玫瑰主色 | `accent #C4647C`，浅底 `#FBEAF0`；收藏、检索与保存操作使用统一主色 |
| 蓝／薄荷／浅黄辅助色 | `#E8EFF8`、`#E8F2EA`、`#FAEBC9`，用于首页入口、图标和主题插画 |
| 尺寸与间距 | 页面左右 16vp，双列间距 12vp，卡片圆角 16vp，主要按钮高度 48vp |

| 详情 | 大幅主题插画、独立标题与摘要、收藏／笔记操作、分段阅读卡和来源说明 |
| 编辑 | 所属档案、正文、完整标签、字数；保留固定保存区、关闭、草稿确认和键盘避让 |

## 实现与真实性

`ArchiveTheme.ets` 集中管理令牌。`ArchiveInfo.ets` 承接会变动的统计、状态与纸片高度；`SiteCard.ets` 承接可观察的筛选结果，双列行 key 包含左右两条 ID，避免右列变化后复用旧卡片。

彩陶、古城、古塔是本项目原创 SVG 主题插画，均在目录和详情保留“主题示意”。不对应具体出土器物、遗址实景、测绘或考古复原。五条文化内容仍为“初稿待校审”。

静态粉彩渐变与波纹只作装饰；官方材质仍由 `HarmonyEffects.ets` 在原生导航区域适配。截图不能证明光效帧率、功耗或真机能力。

本轮没有修改 v1 快照、Preferences 正式库名、删除墓碑或保存流程，不需要格式迁移。跨设备传输仍未接入，设备页如实显示“尚未接入”。

## 验证与截图

真实手机模拟器截图存放在 `docs/design/`，来自 HDC、Hypium 与 UiTest。测试使用独立档案，没有读取正式用户笔记，也没有控制电脑桌面。图集只缩放和排版这些截图，未补画应用界面。

`ArchiveAppearanceTest` 是显式运行的外观审查场景，操作首页入口、收藏、笔记与页签，核对统计、控件范围和纸片范围，采集浅色、深色及 1.5 倍字体截图。自动化断言只覆盖其声明范围，截图仍需人工检查。

```powershell
.\tools\device-test.ps1 -TargetId 127.0.0.1:5555 -TestClass ArchiveAppearanceTest -ExpectedTests 1
```

## 2026-10-14：顶部与 Dock 的原生沉浸光感

根据用户对顶部和底部栏的进一步要求，本轮采用 Yi_Da 的 HDS 原生组件通道：`HdsNavigation.titleBar` 与 `HdsTabs.barFloatingStyle`。底部改为整条官方浮动胶囊，图标、选中态和触摸反馈由原生 `BottomTabBarStyle` 托管；顶部由官方标题栏承载品牌 / 收藏胶囊和原生渐变模糊，内容在栏下方滚动。

没有给底部三张自绘卡片叠加阴影。`HarmonyEffects.ets` 分别管理 HDS 材质能力、标题栏与浮动栏参数；支持时使用 `IMMERSIVE`，强度选择 `ADAPTIVE` 跟随系统。关闭光感或开启减少动态时设为 `NONE` 并关闭滚动材质 / 切页动画，保留可读基础导航。

滚动内容顶部和底部预留净空；原生 Dock 按三个入口自适应宽度，大字模式仍由原生布局承接。测试 ID 通过 `BottomTabBarStyle.id` 保留，原有 NavPathStack、三个页签与快捷入口继续使用同一份状态。

最新截图见 [原生导航截图](design/immersive/README.md)，当前包的结果与失败修复记录见测试报告第 10 节。第 9 节及上面的六页图集保留为此前设计改版记录。

## 2026-10-14：文明连线

首页新增不套浮动卡片的“文明连线”入口，进入五城/个人图谱。插画节点、玫瑰色连线和选中态沿用既有视觉语言；图谱节点可点击，关联列表可打开原生双档案对照 Sheet，再进入原有详情写笔记。

个人专题直接来自真实收藏与笔记标签。演示从二里头和郑州商城的两条观察进入“都城研学”，图谱、共同线索和自己的文字显示在同一条操作路径中。创新重点是把个人记录转成可以探索与比较的关系，而不是增加一张静态概念图。

节点边框显式使用圆角，五城/个人图谱切换重建位置；对照内容顶端对齐并使用页面语义背景。节点高度随实际字体倍率增加，当前手机已查看深色和 1.5 倍字体。Canvas 连线是关系示意；鸿蒙原生材质继续只在受支持导航区域使用。

真实截图与图集见 [文明连线](design/culture/README.md)，操作顺序见 [90 秒演示](DEMO.md)。图谱不表达地理距离或历史因果，五条内容及主题插画的待校审/示意边界不变。本轮测试与中断记录见测试报告第 11 节。

## 2026-10-16：15 条内容与离线交互画布

五城现有 15 条初稿，图谱改为包内 ArkWeb 关系画布，仍使用暖白、玫瑰、同城主色与语义深色资源。点选高亮显示真实关联，节点可以拖动，原生双列索引用于直接选取与大字阅读；关联列表、双档案对照与个人专题继续使用 ArkUI。

画布将每个节点最相关的两条边作为低强调背景，选中节点显示全部线索；减少动态时直接展示稳定布局，不持续流动。图谱不表示地理位置、年代比例或历史传播方向，装饰晕圈不称为原生光感。原有顶部、Dock 和右侧“我的”材质均保持原样。

实际 Three.js 已离线打包；当前模拟器禁用 WebGL，真实显示使用 Canvas 2D 降级，不能将其记为 GPU 验收。15 条内容沿用原创主题 SVG，没有增加未经授权的实景图，全部仍为“初稿待校审”。内容、分类与实现边界见 [内容与图谱说明](CONTENT_GRAPH.md)，本轮结果见测试报告第 14 节。

本轮 13 张真实原图与深色 / 大字检查见 [交互图谱图集](design/graph/README.md)，各图绑定同一主包与实际测试驱动版本。
