# 设计样板轮图集｜2026-10-23

本目录是 **2026-10-23 前端设计样板轮** 的原生画面，来自当前工作区源码构建的未签名 debug 包，
与冻结的 M12 省赛包不是同一个包。引用时请写明“设计样板轮”。

## 设备与包

| 项 | 内容 |
|---|---|
| 手机 | 模拟器 `YunhejiSyncB`，HarmonyOS 7.0.0（API 26），1256×2760，density 560，`127.0.0.1:15555` |
| 包 | 当前工作区 `entry-default-unsigned.hap`，`hdc install` 直接安装，未签名 debug |
| 数据 | 正式档案库中一页真实记忆（演示文本），未清空任何用户数据 |

## 本轮的结构改动（不只是换颜色）

1. **首页**：删掉河卷上的“西／黄河入豫／横向展开”三处标注和面板里的“这一回要找的”说明标签；
   卷目行去掉装饰下划线，只靠字重与颜色区分；开卷卡片去掉三枚 5px 线索小印（进度已在右上角，
   属于重复信息）。河卷只留“题签 + 岸线 + 水面 + 舟”。
2. **篇章页**：原来的“入景／读城／留意”三步条与页头合并成标题下的一条三段进度线，点段即可回到该步；
   刻尺、选项、点灯、观察记收进同一张纸，只用细分隔线分层，不再各自套一个色块；
   “水程／已看见／起点／展开线索／选一个想记住的片段／观察记”等说明标签全部删除，
   只保留刻尺标题、方位读数与系统反馈原文。
3. **图景**：画布内所有 `writing()` 说明字整批删除——它们在手机上只有约 7vp，读不出来；
   开封去掉会读成“亮柱子”的御街窄条，虹桥补了拱腹填色、加深构件，城墙加砖缝与重檐城楼。
4. **字号**：正文以下不再出现 9/10/11px。首页与篇章页正文 14–17，说明文字统一 12–13。
5. **交互缺陷修复**：场景上覆盖的全屏遮罩层没有设 `hitTestBehavior(None)`，
   把“作／居”按钮和拖动画面的手势一起挡住了。修复后两处发现、拖动、滑条都恢复。

## 本轮没有验证

- 平板横竖屏切换与三栏（≥1000vp）布局：本轮未重跑，上一轮的分栏截图已删除，不再当作本轮证据。
- 选摘→摘录卡→UDMF 拖放：本轮未重跑。
- 记忆列表卡片（`MemoryPostcardItem`）仍是旧圆角样式，未纳入本轮统一。
- 其余四城图景沿用旧画法，只受“删除画布说明字、屋面色阶”等共享改动影响。
