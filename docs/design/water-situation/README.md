## 设计说明

- **入口不新增 Tab**：水情是文化浏览的延伸，放在五城河洛之后，用一张细卡进入独立 `NavDestination`。
- **实时优先、回退明确**：首页与页面都优先读服务端 `/water/situation`；成功显示“实时”，缓存显示“上次快照”，失败显示“公开报道”回退，不把回退值伪装成当前报汛。
- **抓取不进 HAP**：源站是 IP + 明文 HTTP + ASP.NET；服务端跟随 302、保留 Cookie、解析 5 列表格，App 只读自有 HTTPS 接口。
- **缺测不补**：8 月 14 日公开报道只有最大流量 2040 m³/s、没有同日水位；实时表格没有含沙量。页面都保留“未给出”或 `null`，不插值、不补 0。
- **图形只做相对比较**：三条公开报道间隔不均，柱高按 2040 归一，标题与脚注都明确“非连续趋势”。
