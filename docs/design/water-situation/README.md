## 设计意图

- **把数据页做成“河面”**：深青渐变、低对比波纹、奶油白数字，和水情主题形成独立视觉身份；首页仍保留纸色，水情卡像一扇望向河流的窗。
- **少即是多**：删掉来源 URL、公开报道背景、长免责声明和“资料说明”，只留下更新时间、实时/离线状态、三站数据、三站对照和两段短解释。
- **数字优先**：水位、流量用 30—34 号字做主视觉；单位缩小并贴近数字，避免“报表感”。
- **可操作**：三站胶囊和流量条都可点击切换主卡；右上角刷新按钮原地重取，不跳页。
- **离线不伪装**：状态只显示“实时 / 上次更新 / 离线数据”，失败时保留上次成功值或内置值，不弹黄框、不堆说明。
- **不做 1.5 倍字体专项**：按手机 1.0 倍的产品视觉验收，不把大字测试作为本功能门禁。

## 工程边界

- 页面只读自有 HTTPS 接口；来源与回退细节留在 `docs/WATER_SITUATION.md`，不进入界面。
- 未做近七日趋势和全站选择；接口返回 16 站，界面展示花园口、高村、利津三个代表站。
