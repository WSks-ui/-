## 设计说明

- **入口不新增 Tab**：水情是文化浏览的延伸，放在五城河洛之后，用一张细卡进入独立 `NavDestination`。
- **首屏先讲边界**：页面第一行就是“公开报道摘录 / 非实时”，避免评委或用户把 88.42 m 当成当前水位。
- **缺测不补**：8 月 14 日黄委通报只有最大流量 2040 m³/s，没有同日水位；卡片显示“未给出”，柱形图也只为流量服务。
- **图形只做相对比较**：三条报道间隔不均，柱高按最大值归一，标题与脚注都明确“非连续趋势”。
- **来源可核对**：每条数值绑定发布者、日期、标题与可复制 URL；文末再次说明“以原发布为准”。
